# Airport Context Guide

这份文件解决一个很实际的问题：

**同样是“机场温度盘”，不同机场的地理位置和微气候特性差很多。**

如果不先把机场对象的地理环境认清楚，就容易犯两类错误：

- 把城市页的温度路径硬套到机场站点
- 看见当前温度在爬，就误以为当天最高温还会按内陆城市那种节奏继续上冲

这份文件不是结算源文档，也不是下单指令。  
它只做一件事：给每个已配置机场一份简短的地理和气候提醒，方便盘前和盘中快速过一遍。

## 怎么用

每次分析前，至少确认这 4 件事：

1. 机场在海边、内陆、湖边，还是盆地/山前
2. 机场离城市热岛远不远
3. 哪种天气机制最容易让高温少一档或多一档
4. 哪些城市页最容易把你带偏

如果一个城市的天气判断和这份机场背景明显冲突，优先怀疑你看错了页面对象或忽略了局地气候。

## 机场摘要

### Amsterdam — EHAM / AMS

- 位置：荷兰西部低地，近北海，海洋性机场。
- 关键特性：低云、海风、冷空气平流都容易压住白天高温。
- 交易提醒：城市页略暖不稀奇，边界桶位别轻信“午后一定还能再冲一度”。

### Ankara — LTAC / ESB

- 位置：安纳托利亚高原内陆，偏干燥、偏大陆性。
- 关键特性：白天升温通常比沿海机场更线性，但云量和风一旦进来，回落也干脆。
- 交易提醒：适合规整尾部 `NO`，但别忽视昼夜温差和干空气导致的整数跳档。

### Berlin — EDDB / BER

- 位置：德国东北部内陆平原，介于海洋性和大陆性之间。
- 关键特性：大多数日子线性，但锋面、低云和冷平流会让峰值掉档。
- 交易提醒：比纯海边盘稳，但不能拿市区页的热岛效应替代机场。

### Brussels — EBBR / BRU

- 位置：比利时中北部，海洋性向内陆过渡。
- 关键特性：常见问题不是极端跳温，而是低云和风场让高温卡在边界档。
- 交易提醒：一旦辅助源对 peak hour 分歧变大，就降级为只做远尾。

### Copenhagen — EKCH / CPH

- 位置：临海机场，受海峡和海风影响明显。
- 关键特性：海洋调节强，云和风足以让看起来很稳的暖尾被削平。
- 交易提醒：城市页和机场页分歧时，优先信机场。

### Doha — OTHH / DOH

- 位置：卡塔尔半岛东岸，靠海湾的大型机场。
- 关键特性：干热背景下多数日子较线性，但海风和近海湿层会影响午后峰值兑现。
- 交易提醒：别把“沙漠城市”直接等同于纯内陆干热盘，海湾调节仍然会让边界桶位打折。

### Dubai — OMDB / DXB

- 位置：阿联酋海岸带，沙漠背景上的海湾机场。
- 关键特性：整体偏干热，但海风、薄云和沙尘能把看似稳的高温压低一档。
- 交易提醒：Dubai 市区和机场感知接近，但仍要先认机场对象，再判断海岸影响有没有放大。

### Dublin — EIDW / DUB

- 位置：爱尔兰东岸，典型海洋性机场。
- 关键特性：升温路径经常被云层和海风限制，不像内陆那样容易暴力冲高。
- 交易提醒：适合纪律化 tail `NO`，不适合把暖城市页当主锚。

### Hong Kong — VHHH / HKG

- 位置：离岸填海机场，南海海洋影响极强。
- 关键特性：海风、湿度、低云对峰值时段和最终高温影响很直接。
- 交易提醒：看上去只差一度时，尾盘风险往往比内陆城市更大。

### Lisbon — LPPT / LIS

- 位置：葡萄牙西岸，接近大西洋海洋调节带。
- 关键特性：海风能把午后高温削掉一档，城市页可能比机场更暖。
- 交易提醒：暖尾盘要特别看风向和下午升温是否中断。

### London — EGLC / LCY

- 位置：伦敦东部，近河口和海洋输送通道。
- 关键特性：海洋性低云、雾、河口附近风场都可能压住机场高温。
- 交易提醒：London 城市页经常比机场对象更暖，是典型错锚污染源。

### Madrid — LEMD / MAD

- 位置：伊比利亚高原内陆，干热、大陆性明显。
- 关键特性：多数晴空日线性强，但一旦薄云、冷空气残留或风向不对，就会比市场想象的更保守。
- 交易提醒：表面上很“好懂”，但 exact 附近仍然别因为内陆属性就放松。

### Miami — KMIA / MIA

- 位置：南佛州沿海平原，强烈热带海洋影响。
- 关键特性：海风、午后对流、云量是决定高温能否再摸一档的核心。
- 交易提醒：别把海滩/市区体感热度误当机场结算路径。

### Munich — EDDM / MUC

- 位置：巴伐利亚内陆，接近阿尔卑斯前缘。
- 关键特性：锋面和焚风风险会让日高温分布出现非线性跳跃。
- 交易提醒：Munich 不是“普通欧洲内陆盘”，近档 exact 风险要额外打折。

### New York — KLGA / LGA

- 位置：纽约沿海都市圈，海洋和城市热岛混合。
- 关键特性：海风能显著压机场高温，而 Manhattan/城市页常常更暖。
- 交易提醒：KLGA 和 Manhattan/NYC 城市页不是一回事，这里错锚最常见。

### Paris — LFPG / CDG

- 位置：巴黎北部内陆机场，海洋性和内陆性混合。
- 关键特性：春季锋面、降水和低云会让市场以为能继续升温时突然回落。
- 交易提醒：Paris 市区页偏暖并不罕见，LFPG 更应该看锋面和云量。

### Rome — LIRF / FCO

- 位置：靠近地中海的机场，海洋调节明显。
- 关键特性：海风和云量会影响午后高温，但通常没热带沿海机场那么剧烈。
- 交易提醒：城市页略暖可以理解，但不该拿来覆盖机场主锚。

### Osaka — RJBB / KIX

- 位置：大阪湾离岸机场，海洋性影响强。
- 关键特性：海风、低云和海湾边界层会让机场口径明显不同于大阪市区热岛。
- 交易提醒：别拿 Osaka 城区页替代 KIX，近档 exact 特别容易被“市区更热”这个错觉污染。

### Seoul — RKSI / ICN

- 位置：沿海大型机场，受黄海和海风影响明显。
- 关键特性：低云、海风和潮湿空气会让边界桶位非常敏感。
- 交易提醒：数据质量高不等于盘好做，沿海机场在 1 度边界上经常惩罚懒判断。

### Shanghai — ZSPD / PVG

- 位置：东海沿岸大型机场，远离市中心热岛。
- 关键特性：海风、湿度、霾和低云都可能让机场比城市页更冷一到两档。
- 交易提醒：上海市区页经常比浦东机场暖，这是最典型的错锚来源之一。

### Singapore — WSSS / SIN

- 位置：赤道海洋环境中的沿海机场，热带海洋性极强。
- 关键特性：云量、湿度和午后对流会直接决定峰值时段能否兑现，不稳定性高于温带机场。
- 交易提醒：这类盘最怕把“常年很热”当成线性上冲逻辑，真正的风险往往是云和雷阵雨把高温削平。

### Taipei — RCTP / TPE

- 位置：台湾北部沿海机场，受海洋和季风影响。
- 关键特性：锋面、低云、海风和潮湿空气都会让高温档位很敏感。
- 交易提醒：台北市区和桃园机场不是一回事，城市热岛和机场口径经常分离。

### Tokyo — RJTT / HND

- 位置：东京湾沿岸机场，强海洋影响。
- 关键特性：海风和云层对午后峰值的限制很常见，市区热岛也容易制造错觉。
- 交易提醒：不要把东京市区热岛路径直接套到 Haneda。

### Toronto — CYYZ / YYZ

- 位置：安大略湖附近，受湖效应和冷暖平流影响。
- 关键特性：风向变化会让升温路径突然偏离，尤其在过渡季节。
- 交易提醒：这是典型“看起来像普通内陆盘，实际上被湖影响”的机场。

### Vienna — LOWW / VIE

- 位置：多瑙河平原，偏大陆性盆地结构。
- 关键特性：多数日子较规整，但逆温、薄云和风场会让高温卡边界。
- 交易提醒：别因为 Vienna 没有海风就假设峰值一定线性兑现。

## 执行要求

这份机场背景不是“读过一次就算了”的资料。

每次盘前或盘中判断，都至少回答一句：

- 今天这个机场的地理/微气候机制，有没有让主锚比城市页更冷或更热的理由？

如果回答不上来，就说明还没把机场对象看透，不该直接下结论。
