工程边界

  • Skill 提供 PIT、固定分母、forward 和生产安全规则。
  • Harness 把这些规则变成状态、权限和完成判定。
  • Typed tools 执行真实计算；Planner 不能直接修改结果。
  • EvidenceLedger 使中断恢复和事后审计成为默认能力。
  • 生产 controller、真实下单和部署仍在 Harness 外保留显式授权。
