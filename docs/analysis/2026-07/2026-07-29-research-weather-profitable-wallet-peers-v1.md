## 与种子钱包对比

种子钱包官方 Weather 排行榜为 ALL +$19,533 / $630k（3.10%），MONTH
+$4,956 / $214k（2.31%），WEEK +$301 / $19.4k（1.55%）。其近期样本有
67.0% 买入资金位于 >=95¢，明显比上述候选更依赖高价 NO / 临近结算，但既有
逐笔复盘显示利润主体并非来自这一档。

候选可以分成三种机制：

1. **主动调仓型**：`0x496f...`、`yourthos`。大量 SELL，偏 NO，利用盘口和
   概率变化退出，不只等结算。
2. **方向分散型**：`badatmath.`、`0x43cb...`。几乎只买 YES、跨大量城市和
   bracket 分散，主要持有到结算。
3. **小资金高效率型**：`Gptball`。绝对 PnL 不大，但价格不极端、近期和累计
   PnL/volume 都较高，是最值得拆 signal 来源的地址。

## 筛选与限制

- 候选来自 Polymarket Data API 的 `WEATHER` 分类 ALL / MONTH / WEEK
  排行榜，以及 2026-07-28 至 07-29 活跃 temperature markets 的公开交易者。
- 盈利使用官方 category PnL；交易风格使用每个钱包最新最多 5,500 条公开
  activity，在客户端严格过滤 `highest temperature`。
- 价格占比以 BUY 的 `usdcSize` 加权。近期 activity 是截断样本，只用于判断
  “是否 99¢ 型”和执行风格，不能代替完整逐日 cashflow。
- 没有公开其天气预报、信号全集和未成交订单，因此不能证明其 alpha 来源，
  也不能把排行榜 PnL 直接当作可复制收益。
- `closed-positions.realizedPnl` 在双边回转和剩余仓位下会严重失真，本报告没有
  用其为最终盈利排序。
