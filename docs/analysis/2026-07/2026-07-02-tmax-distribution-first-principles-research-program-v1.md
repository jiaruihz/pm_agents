# T_max 分布引擎：第一性原理研究纲领 v1

> 前提：不做速度竞争（结算源时差/修订抢跑不是我们的赛道），走天气模型路线。
> 数据补建（first-seen 采集、payload 落日志）另见测量实验文档，本文不重复。
> 现有结论（含审稿文档里的）一律当"待重检假设"而非事实。

---

## 1. 这个市场在定价什么：一个被离散化的运行最大值

城市最高温市场的标的不是"明天多热"，是 **T_max = max over day of T(t)** —— 一条部分观测路径的
运行最大值，再经结算刻度（整数 °F / 0.5°C）离散成 bracket。数学对象是 lookback/hazard 结构：

```
T_max = max( running_max_t , max_{s>t} T(s) )
```

在任意决策时刻 t，第一项已知（差一个 basis），全部不确定性在第二项——**"剩余路径最大值"的条件分布**。
整排 bracket 的 YES 价格 = 市场对这个条件分布的离散化报价。

所以这个策略的本体从来不是"买 current NO 还是 d1 NO"，而是：
**你有没有一个比市场更准的 P(T_max ∈ bracket_k | 当前状态) 条件分布。**
runway / capped / pullback / plateau 全部是这个分布的投影切片。现在的问题是只做了投影，没做分布。

## 2. 慢玩家的结构性优势位：融合，不是速度

市场参与者定价 T_max 时可用的信息只有两块，都是公开的：预报（NWP 小时曲线）和已实现观测路径。
观察市场行为的合理先验是：**大多数报价者在两个锚之间切换** ——

- **forecast 锚**：价格贴着预报 max 摆，忽略今天路径已经偏离预报的证据；
- **running-max 锚**：价格贴着已实现高点摆，忽略剩余强迫（你们 runway 的原始直觉）。

正确答案是贝叶斯融合：先验 = 预报小时曲线（含不确定度），似然 = 今日已实现路径对预报的偏离。
**融合是建模技能，不是速度技能**——状态 10–30 分钟才实质变化一次，慢 runner 完全够。
这就是天气模型路线的 alpha 论点，比"我们比市场懂天气"更精确：
**我们不需要比 ECMWF 懂天气，只需要比市场的锚切换启发式更会做条件化。**

这个论点还可以直接用现有数据检验（见 §6 P0）：分小时段比较市场隐含 max 与两个 naive 锚的贴合度。
如果隐含价格上午贴 forecast 锚、下午贴 running-max 锚，锚切换假说成立，且切换时段就是分歧交易的
最佳窗口。这一步零建模。

## 3. 研究目标函数必须换：从 selected-trade ROI 到全量分布评分

现在所有结论的共同软肋：以 selected trades 的 ROI 为目标函数，有效样本 = 几十个交易日，
任何切片/阈值动作都在消耗本来就不够的自由度。"结论未必准确"的根源就在这里——包括
"edge 只在 marginal 带"这种审稿判断，本身也可能是 current/d1/d2 表达网格 + ask band 选样的伪影。

换成：**在全量 city-day-hour 状态行上，用 proper scoring rule（log-loss / Brier / CRPS）
比较三方的 T_max 分布预测：**

1. 市场隐含分布（整排 bracket 的 mid/ask 归一化）；
2. 两个 naive 锚（forecast-only、runningmax-only）；
3. 我们的模型。

atlas 已有 ~13k state rows 且逐日增长——这是真实的有效样本量，比 263 笔 selected trades 大两个
数量级。评分不选样、不设阈值、不挑表达，天然免疫过拟合三件套（样本切碎、阈值调参、选样偏差）。

**纪律**：模型必须在冻结 forward 的 scoring rule 上稳定打败市场隐含分布，才有资格进入表达层讨论。
打不败，任何 route/gate/sizing 都是在噪声上雕花。这一条同时是对"现有结论未必准确"的系统性回应：
分布评分框架会自动重检 atlas 的所有 regime ROI 结论，而不依赖它们。

## 4. 状态变量按物理重构（每个都有机制，不是切片）

**a) 预报曲线整条用，不是标量。**
现在只用 forecast_max 和 peak_hour 两个标量。物理上有效的是曲线泛函：
剩余 headroom `max_{s>t} F(s) − current`、**高于当前档上沿的剩余度-小时** `∫(F(s) − bracket_upper)⁺ ds`
（打穿所需的"能量"）、太阳时标下的峰位置。

**b) 今日路径追踪残差（可能是最有价值的单一特征）。**
`resid_t = 已实现 T(t) − 预报曲线 F(t)`，及其日内均值/趋势。它是"今天预报错多少"的实时估计，
日内自相关强：今天跑热的日子，最终 max 大概率也超预报。frozen forward 的失败诊断里
`forecast_error_native` 从 0.09 漂到 0.92——市场后期在系统性高估的预报环境里被 runway 路由反复
收割，而追踪残差在当天上午就能看见这件事。这是 Karachi 型失败的解药，也是融合模型的"似然"项本体。

**c) 度内小数位置（市场的结构性盲区）。**
running max = 84.9°F 和 84.0°F，escape 概率天差地别，但两者的 bracket 报价完全相同——bracket
价格无法表达度内信息。同理 forecast max 的小数位置（65.3 vs 65.9 对"打穿 65"完全不同，Seattle 案）。
`running_max mod 1`、`forecast_max mod 1`、两者到档边界的连续距离，是慢速可采、对手看不见的
状态变量。这也是把结算刻度从"口径 bug"升格为"定价维度"的方式。

**d) 约束变量（capped 侧的物理本体）。**
湿气团上限：T_max 很难超过露点/气团结构给出的湿上限（Bowen 比、湿静力能约束）——
`dewpoint_depression` 系列不只是降权因子，是 tail 分布的物理截断。云量、风混合方向
（onshore 封顶 / 干燥下混增温，按地理定号）同属此层。

**e) Ensemble 分歧 = 分布宽度。**
`gfs_forecast_max − ecmwf_forecast_max` 的绝对值是预报不确定度的第一性度量。模型一致的日子
条件分布应当窄（尾部 bracket 的 YES 贵了就卖），分歧日应当宽（避开或反向）。市场大概率给所有
日子差不多的隐含宽度——这是一个慢速相对价值维度，字段（`forecast_peak_models_agree_le_1h`、
两模型 gap）已经在 atlas 里躺着没用。

**f) 时间轴换成太阳时标（顺带对冲最大的有效性威胁）。**
全部样本都是 5–6 月。用 `decision_hour_local` 训练的任何东西到 8 月都会漂。
换 `hours_to_solar_noon`、太阳高度角、当日可照时长——物理协变量是小样本对抗季节漂移的唯一防御。

**g) hazard 的时间衰减形状。**
新高 hazard 在太阳峰后、无平流强迫时塌缩，形状由物理决定。current-bracket NO 的价值随时间的
衰减（"theta"）因此有一个可计算的期望形状；若市场把这个衰减定价得太平或太陡，就是不需要速度的
错价。theta_no 线的老直觉在这里获得机制化的第二生命。

## 5. 模型与表达的分层

**模型层**：从上述状态变量到整排 bracket 分布。两个候选形态：
- 逐度 competing-risk hazard：P(至少再升 1 度 | 状态)、P(至少 2 度 | 已升 1 度)……链式给出全分布，
  每一级都是二分类，可解释、可校准；
- distributional regression（直接回归剩余升温量的分布）。
城市间用**气候族层级 + 物理协变量共享强度**（shrinkage），禁止 per-city 自由偏置——风向 sector 表
的教训：38 天 × 单城市的自由参数一定拟合噪声。

**表达层**：模型分布 vs 市场隐含分布逐格比较，交易分歧最大、每单位 spread EV 最高的格子。
runway current NO 和 capped d2 NO 自动作为两种分歧形状的特例落出，不再需要 route 硬编码。
白送一类新表达：**隐含分布形状违背**——相邻 bracket 报价违反单调 hazard / 归一约束时，
买被压的格子。这是模型 RV，分歧存在几分钟到几小时，range_rv 线可以直接合流进来。

硬边界只保留三种（机制边界，不是补丁）：结算刻度 margin < 1 单位；太阳峰后且无强迫的 current NO；
已知坏数据。其余一律进分布，由 EV 说话。

**现有 regime 的去向**：不废弃，降维。day_regime/intraday_state 变成模型的分层特征和诊断切片；
atlas 继续作为特征工厂和 forward ledger。血缘一条不动。

## 6. 优先级（不含数据补建，全部用现有 13k rows 可启动）

**P0 — 锚切换检验 + 三基准评分台（零建模，1–2 天）**
把 state rows 的整排 bracket 报价归一成市场隐含分布，与 forecast 锚、runningmax 锚两个 naive
分布同台打分（log-loss/Brier，按 city-day block bootstrap）。回答三个问题：市场像哪个锚？
分小时段锚是否切换？两个 naive 锚有没有谁能直接打败市场（如果有，edge 比想象的浅得多）。
这一步的输出决定后面所有投入的先验。

**P1 — 融合特征三件套（追踪残差 + 度内小数位置 + 太阳时标）**
加进一个最简 hazard 模型（逐度 competing risk，气候族分层），验收 = 冻结 forward 上对市场隐含
分布的 scoring rule 增量。不看 ROI。

**P2 — 约束层（湿上限 / 风混合定号 / ensemble 宽度)**
同一验收标准。每个特征单独消融，增量不显著就扔，不进 soft weight 续命。

**P3 — 表达优化器 + 形状违背 RV**
模型在 P1/P2 通过评分门之后才开工。selected-trade ROI 在这里才重新出场，作为执行层 sanity check，
带 spread/容量约束，衔接既有三道 live gate。

每一步的验收都写在开工前，冻结 forward 切分沿用 6/21 线并逐周滚动。

## 7. 预期的诚实版本

这条路线赢的条件是明确的：市场的边际报价者确实在跑锚启发式，而融合 + 度内信息 + 约束物理
能在分布评分上稳定挤出几个百分点的 skill。P0 一两天就能看到这个前提像不像真的。
如果 P0 显示市场隐含分布已经打败所有 naive 锚且校准良好——那说明对手盘比假设的聪明，
这条线的天花板就很低，及早知道也是收获。

分布评分的另一个红利：**它把"策略死没死"的判定从等 60–90 天 forward ROI，缩短到每周看一次
scoring rule 曲线**——分数是每个 city-day-hour 都结算的，不用等赌注翻牌。
