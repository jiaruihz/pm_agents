# OpenAI 2026 硬件分支 edge 研究 - 2026-06-09

## 结论先行

这组市场目前最适合做 **手动研究 + 分支条件单**，不适合无脑复制任何钱包。核心 edge 不在“OpenAI 会不会做硬件”，这个已经很明显；edge 在：

1. **announce vs ship**：规则只要求 2026 年底前 OpenAI 官方公开宣布，不要求 2026 发货。
2. **first device vs family**：第一个原型的形态不等于 2026 年官方可能宣布的整个硬件 family。
3. **category wording**：同一个设备可以让多个类别同时 YES，但每个类别仍要符合市场标签本身，例如 `Computer (Laptop/Desktop)` 不是泛泛的“AI computer”。
4. **钱包分歧**：高分 tech 钱包不是同向共识，分歧本身说明这里还有研究空间。

当前我会优先盯三条：

| 优先级 | 分支 | 当前倾向 | 适合动作 |
|---|---|---:|---|
| 1 | Phone | 偏 NO | 最适合做规则/fact edge；如果 NO 价格没有被打到 90%+，可作为主观察分支 |
| 2 | Earbuds/Headphones | 偏等 spike 后反向 | Sweetpea 传言最拥挤；若 YES 被传言继续拉高，再研究 NO 更合适 |
| 3 | Glasses | 仅 watchlist，不急下 | `cqk` 大仓 YES，但外部事实还不够支持直接跟 |

不建议现在主动追：necklace / ring / tablet / HMD / computer YES。它们要么被“不是 wearable / 不是 in-ear”压制，要么市场标签比外部叙事更窄。

## 外部事实证据

### 官方事实

OpenAI 官方信确认，io Products 团队已经并入 OpenAI，Jony Ive 和 LoveFrom 保持独立但承担 OpenAI 深度设计职责；官方也明确说这个团队会与 OpenAI 的研究、工程、产品团队更紧密合作。

来源：[OpenAI - A letter from Sam & Jony](https://openai.com/sam-and-jony/?authuser=0)

OpenAI 2026 年 1 月的美国硬件制造 RFP 明确覆盖 `Consumer Devices`，包括 final assembly, PCB assembly, displays & optics, mechanical tooling, electromechanical modules, packaging 等。这确认 OpenAI 不是只做概念视频，而是在拉硬件供应链。

来源：[OpenAI RFP - U.S. Hardware Manufacturing](https://cdn.openai.com/pdf/rfp-for-us-hardware-manufacturing.pdf)

### 对分支最关键的非官方/法律文件证据

TechCrunch 报道法院文件称，Tang Tan 在声明中说 Altman 提到的原型 **不是 in-ear device，也不是 wearable device**，且设计尚未最终定型；报道还提到它可能是能放进口袋或放在桌上的“third device”。

来源：[TechCrunch - Court filings reveal OpenAI and io's early work on an AI device](https://techcrunch.com/2025/06/23/court-filings-reveal-openai-and-ios-early-work-on-an-ai-device/)

WIRED 进一步报道，OpenAI 后续法院文件显示其不会用 `io` 名称销售 AI hardware，且第一款设备不会在 2027 年 2 月底前发货；但此前 OpenAI 仍计划 2026 年下半年 unveil。注意：这对 Polymarket 不直接利空，因为规则只要求 announcement。

来源：[WIRED - OpenAI Abandons io Branding for Its AI Hardware](https://www.wired.com/story/openai-drops-io-branding-hardware-devices/)

Axios 报道 OpenAI 的 Chris Lehane 在 Davos 表示，OpenAI 第一款设备仍在 2026 年下半年 unveil track 上，但没有承诺 2026 年销售。

来源：[Axios - OpenAI aims to debut first device in 2026](https://www.axios.com/2026/01/19/openai-device-2026-lehane-jony-ive)

## 分支逐项判断

### 1. Phone

当前倾向：**偏 NO，是最好的主研究分支。**

理由：

- 外部叙事多次强调不是 smartphone，而是 phone/laptop 之外的 third device。
- Altman/Lehane 描述的“更 simple / 更 peaceful / screenless / pocket or desk”不自然等于 phone。
- 市场标签是 phone，不是 “phone replacement” 或 “mobile AI device”。
- `traboukos` 大 NO phone，和这个事实路径一致。

反向风险：

- 如果 OpenAI 官方说“phone-like device”或发布有蜂窝通信、系统级通讯、独立移动计算定位的设备，UMA 可能把它归为 phone。
- `cqk` 大 YES phone，说明有聪明钱包在押相反解释。

手动触发：

- 如果 NO phone 仍在 80-85c 区间，且没有新的 OpenAI 官方 phone-like 证据，可以继续作为第一优先。
- 如果 YES phone 因传言冲到 25c+，更适合重新评估 NO。

### 2. Earbuds / Headphones

当前倾向：**不追 YES；等传言 spike 后研究 NO。**

理由：

- 这是最高成交量和最高 YES 价格分支，Sweetpea 传言已经明显被市场消费。
- 法院文件里的 “not in-ear device” 明确冲击传统 earbuds。
- `cqk` 持 NO earbuds，且这个钱包 tech 风格更干净。

反向风险：

- 传言里的 behind-ear / open-ear audio device 未必是 in-ear，但仍可能被市场归为 headphones。
- OpenAI 如果官方宣布 “AI audio companion / headphones” 级别文案，会直接打穿 NO。

手动触发：

- YES <25c 不碰；YES 35-45c 以上且官方仍无 audio/headphones wording 时，才值得研究 NO。
- 若 OpenAI 官方出现 `audio wearable`, `headphones`, `earbuds`, `Pods` 之类措辞，应立即降低 NO 置信。

### 3. Glasses

当前倾向：**watchlist；不急着买 YES。**

理由：

- `cqk` 最大仓是 YES glasses，这是所有钱包信号里最值得认真看的单点。
- OpenAI RFP 提到 displays & optics，行业方向上 Meta/Google 都在押 AI glasses。
- 但法院文件说首个原型不是 wearable；screenless/pocket/desk 叙事也不支持第一款是 glasses。

反向风险：

- “first prototype not wearable” 只约束第一个 prototype，不约束 OpenAI 2026 年是否宣布 family 中的 glasses。
- 一个官方 roadmap 如果直接说正在做 AI glasses，即可 YES。

手动触发：

- 需要新的官方/强可靠证据再动。比如 OpenAI 官方招聘/供应链/公开演示明确出现 optics/display/glasses。
- 单靠 `cqk` YES glasses 不够。

### 4. Clip-on device for clothing

当前倾向：**偏 NO，但价格已经偏高，等待更好入场。**

理由：

- Clip-on 很像 Humane AI Pin 叙事，但 Humane 失败是行业负面样本。
- 法院文件 “not wearable” 对 clip-on clothing 是直接负面。
- 21-26c 的 YES 对当前证据偏贵。

风险：

- 如果 pocket/desk third device 最终被设计成可夹衣服的辅助形态，YES 会被触发。

手动触发：

- 如果 YES 被炒到 30c+ 且没有 wearable 证据，可以看 NO。

### 5. Watch

当前倾向：**偏 NO，但不是最好分支。**

理由：

- Watch 是典型 wearable，和 court filing 冲突。
- `traboukos` / `ooops` 都偏 NO watch。

问题：

- NO 约 85c，收益空间比 phone 小。
- Apple ex-Watch/camera/hardware 人才加入只能说明能力，不等于 OpenAI 会宣布 watch。

手动触发：

- 只在 NO <83c 或 YES 被传言拉高时考虑。

### 6. Necklace

当前倾向：**偏 NO，但当前 NO 太贵，不优先。**

理由：

- Necklace 是 wearable，和 court filing 冲突。
- 价格已经在 10c YES / 90c+ NO 附近，不符合“不要 90%+”偏好。

手动触发：

- 只有在新传言把 YES 拉到 15-20c，且仍无官方 wearable 证据时才值得看。

### 7. Ring

当前倾向：**偏 NO，不优先。**

理由：

- Ring 是 wearable，事实侧不支持。
- 市场流动性和成交量都一般。

手动触发：

- 基本只作为 NO wearable basket 的小确认，不单独主交易。

### 8. Head-mounted display

当前倾向：**偏 NO / avoid。**

理由：

- HMD 是更强的 wearable/display device，和 screenless / pocket-or-desk 原型冲突。
- `cqk` 是 NO HMD，但 `CryptoGerm` 是 YES HMD，钱包分歧大。

风险：

- OpenAI RFP 里有 displays & optics，长期可能支持 XR/AR 方向。
- 如果官方宣布 family，并把 optics/headset 作为路线图，HMD YES 可触发。

手动触发：

- 当前不主动；等官方 optics 证据。

### 9. Tablet

当前倾向：**NO/ignore。**

理由：

- 没有看到支持 tablet 的强事实链。
- 低成交量，难作为主 edge。

手动触发：

- 除非官方出现 screen/tablet/prototype leak，否则忽略。

### 10. Computer (Laptop/Desktop)

当前倾向：**偏 NO，但要小心规则语言。**

理由：

- 外部叙事说“new generation of AI-powered computers”，容易让散户把 `computer` 买高。
- 但市场标签是 `Computer (Laptop/Desktop)`，不是 generic computer。
- pocket/desk/screenless third device 不自然等于 laptop/desktop。
- `traboukos` 持 NO computer。

风险：

- 如果官方把产品叫做 “computer” 且形态可放桌上，UMA 争议可能出现。
- 如果官方发布类似 desktop hub / smart speaker with compute，是否算 desktop computer 需要规则律师判断。

手动触发：

- YES computer 被叙事拉高到 18-22c 且没有 laptop/desktop 证据时，看 NO。
- 当前 NO 约 88c，略接近用户不喜欢的高确定性区间。

## 当前最实用的跟单/研究策略

### 策略 A：规则反向 NO phone

适合度：高。

逻辑：

```text
官方硬件确定存在
但第一设备叙事 = third device / screenless / pocket or desk / not phone
市场 phone YES 仍有 18c 左右
=> phone NO 是更干净的 category edge
```

需要跟踪：

- OpenAI 官方是否使用 phone / smartphone / mobile device / cellular / calling 等词。
- `cqk` 是否继续加 YES phone；如果它减仓，NO 置信上升。
- `traboukos` NO phone 是否加仓或退出。

### 策略 B：等 Sweetpea 把 earbuds 推高，再做反向

适合度：中高。

逻辑：

```text
Sweetpea 传言推动 earbuds YES
但法院文件明确 not in-ear，且 OpenAI 未官方确认 audio/headphones wording
=> 不追 YES，等拥挤后看 NO
```

关键风险是 behind-ear/open-ear 也可能被市场当成 headphones，因此这个分支不能只看字面 `not in-ear`。

### 策略 C：`cqk` glasses watchlist

适合度：中。

逻辑：

```text
最强 tech 钱包大仓 YES glasses
但当前事实不够支持
=> 不是现在跟单，而是建立触发器
```

触发器：

- OpenAI 官方/招聘/RFP/供应链出现 glasses/optics/display wearable 明确信号；
- glasses YES 价格没有先涨穿 30c；
- `cqk` 没有明显撤仓。

## 不建议的动作

- 不建议买 90%+ 的 NO necklace / NO ring 当主交易；赔率空间不符合要求。
- 不建议追 YES earbuds；这已经是最拥挤的传言分支。
- 不建议因为 “OpenAI hardware is real” 就买 YES computer/phone/watch。这个市场结算的是具体 category，不是硬件存在本身。
- 不建议直接复制 `CryptoGerm` 的广撒 YES basket；这更像低价 optionality，不是可解释 edge。

## 后续监控清单

每日/隔日看：

1. Polymarket price move：phone YES, earbuds YES, glasses YES。
2. Top holder 变化：`cqk`, `traboukos`, `CryptoGerm`, `ooops`。
3. OpenAI 官方：blog, RFP, careers, official video, product event。
4. 法院文件/商标案：是否继续泄露形态、ship/announce 时间线、命名策略。
5. 供应链传言：只作为 price catalyst，不作为单独下单依据。

## 当前手动操作建议

如果现在必须选一个最适合深入跟踪的方向：

1. **主分支：NO phone**
   - 规则最清楚，事实链最顺，价格也不是 90%+。
2. **条件分支：NO earbuds/headphones**
   - 只在 Sweetpea 传言导致 YES 再上行时考虑。
3. **观察分支：YES glasses**
   - 等新证据，不先手。

这不是自动下单建议。实际下单前还要再跑一次当日价格、orderbook 深度、top holder 增减仓，以及 OpenAI 官方/法院文件是否有新增信息。
