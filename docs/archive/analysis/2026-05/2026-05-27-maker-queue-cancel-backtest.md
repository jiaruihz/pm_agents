# maker_queue_v1 撤单回测：不同阈值下的 PnL 模拟

> 分析日期：2026-05-27  
> 数据：B 策略（c13ccf0c3181）CLOB 成交单，3 天（5/24–5/26），50 fills  
> 问题：挂单超过多少小时撤单，可以最大化 PnL？

---

## 核心结论

**推荐撤单阈值：4 小时（`cancel_after_minutes = 240`）**

- 保留前 4h 内的 31 笔成交（WR 54%，PnL +$7.30）
- 撤掉 4h+ 的 19 笔（已结算 WR 仅 29%，PnL −$11.27）
- 模拟后 PnL：**+$7.30**（vs 实际 −$3.97），节省 **+$11.27**

|---|---|---|---|---|---|

**关键发现**：超过 2h 的成交单 WR 骤降至 33–40%（vs 快速成交的 50–100%），且整体负收益。  
这是 **adverse selection 的统计信号**：慢成交 = 市场信息已更新 = 你的旧单变成被动被吃。

## 为什么 4h 优于 2h？

| 分析项 | 2h 撤单 | 4h 撤单 |
|---|---|---|
| 保留笔数 | 22 | 31 |
| 撤销笔数 | 28 | 19 |
| 保留 settled PnL | +$2.58 | +$7.30 |
| 节省量 | +$6.55 | +$11.27 |
| 2h-4h 区间特点 | 丢失 NYC +$4.72 | 保留 NYC +$4.72 |
| 4h+ 区间特点 | — | 撤掉 Miami×2 (−$10.09)、LA (−$4.39)、etc. |

在 2h-4h 区间，NYC 这一笔赢单拉高了整体，说明 2-4h 区间仍有有效信号。  
4h+ 区间才是 adverse selection 最严重的区域（WR 29%，以 Miami 两笔为代表）。

**方向性建议**：`cancel_after_minutes = 240`（4h），后续数据积累后可进一步精调。

## 对 maker_queue_v2 的参数建议

基于本次回测 + baseline 分析，推荐 v2 配置：

```json
{
  "execution_policy":           "maker_queue_v2",
  "quote_improvement_ticks":    0,        ← 从 1 降到 0（直接挂 mid，提高 fill 率）
  "cancel_after_minutes":       240,      ← 新增：4h 未成交撤单
  "max_mid_drift":              0.03,     ← 从 0.1 收紧到 3%（价格漂移撤单）
  "chase_enabled":              false,    ← v2 先不追单，只撤单
  
  "tick_size":                  0.01,
  "narrow_quote_spread":        0.03,
  "max_quote_spread":           0.12,
  "min_quote_edge":             0.03,
  "adverse_selection_spread_fraction": 0.5,
  "wide_spread_shade_ticks":    1
}
```

**v2 预期改善**：
1. `quote_improvement_ticks=0`：fill 率从 55% → 接近 70%（减少 miss 的信号）
2. `cancel_after_minutes=240`：节省 4h+ stale order 亏损（基于已有数据估计 ~$11/3天）
3. `max_mid_drift=0.03`：价格漂移 3% 时撤单，防止信息失效后才被吃单

## 回测局限性

1. **样本量极小**：50 fills，19 settled，结论方向可信但数字误差大
2. **大量 N/A**：28 个 stale 订单中 20 个尚未结算，真实影响尚未显现
3. **无 Chase 模拟**：场景 C（撤后追单 re-queue）需要半小时盘口快照数据，当前无法回测
4. **阈值拟合风险**：4h 结论基于极少已结算样本，不排除过拟合
